# RCBT Milestone Registry

Complete means shipped to production and QA-verified, not code landed. A row
flips to Complete only when its QA checklist is green and the change is live
and verified. This registry, with the QA checklists, is the only completion
authority.

| id | name | scope | brief(s) | change class | status | date | QA checklist | rollback id |
|----|------|-------|----------|--------------|--------|------|--------------|-------------|

Status values: Complete, In progress, Planned, Paused, Cancelled.
